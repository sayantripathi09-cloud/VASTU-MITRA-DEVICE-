VASTU MITRA DEVICE

CORE FEATURES

  • 8 Direction Digital Compass System (HMC5883L)
  • Real-time heading detection (0° to 360°)
  • India magnetic declination correction (~13°)
  • Stable direction mapping: N, NE, E, SE, S, SW, W, NW

VOICE SYSTEM (DFPLAYER MINI)

  • Audio-based navigation guidance system
  • Direction announcement (North, East, etc.)
  • Degree-wise voice output (0–360 mapping)
  • Startup & scan voice feedback
  • Hold mode voice support

CONTROL SYSTEM

  • BTN1 → Detail Info Mode
  • BTN2 → Scan / Hold Mode
  • BTN3 → Manual Direction Cycle

LED & BATTERY SYSTEM

  • WS2812 direction color indication system
  • Battery monitoring via ADC
  • Low battery warning (3.7V)
  • Auto shutdown (3.5V safety limit)

SYSTEM MODES

  • IDLE MODE
  • SCANNING MODE
  • HOLD DIRECTION MODE

SMART FEATURES

  • Auto idle detection (10s)
  • Watchdog auto recovery system
  • Button debounce protection
  • Non-blocking firmware design

HARDWARE USED

  • Arduino / AVR Microcontroller
  • HMC5883L Compass Sensor
  • DFPlayer Mini Module
  • WS2812 RGB LEDs
  • Battery sensing circuit
