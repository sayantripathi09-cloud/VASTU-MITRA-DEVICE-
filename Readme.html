VASTU MITRA DEVICE

CORE FEATURES

  • 8 Direction Digital Compass System (HMC5883L)
  • 0°–360° real-time heading detection
  • India magnetic declination correction (~13°)
  • N, NE, E, SE, S, SW, W, NW mapping

VOICE SYSTEM

  • DFPlayer Mini audio guidance
  • Direction + degree voice output
  • Startup + scan + hold voice system

CONTROL SYSTEM

BTN2 → Scan / Hold

BTN1 → Detail Info Mode

BTN3 → Manual Direction Cycle

LED + BATTERY SYSTEM

  • Color-coded compass directions
  • Battery indicator LED (Green/Blue/Yellow/Red)
  • Low battery warning at 3.7V
  • Critical cutoff at 3.5V

SYSTEM MODES

  • IDLE
  • SCANNING
  • HOLD_DIRECTION
